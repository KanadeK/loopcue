# Security

Only the latest 0.1.x release receives fixes. Report vulnerabilities privately through [GitHub private reporting](https://github.com/KanadeK/loopcue/security/advisories/new). If that channel is unavailable, open an issue requesting a private contact without posting exploit data or secrets. Do not include real captures or logs.

The tool runs locally and has no runtime network feature. Local reports and outputs may still reveal metadata or contain input data: inspect the README's security boundary before sharing them. No tool here provides encryption or an operating-system sandbox. Use an updated Python and Git where applicable.
